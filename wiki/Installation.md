# Installing docxi: requirements, Bundler setup and upgrading

docxi is a pure-Ruby gem. Installing it pulls in two dependencies, nokogiri and rubyzip, and nothing else. No office software is needed.

## Requirements

| Requirement | Version |
|---|---|
| Ruby | 2.5 or newer |
| nokogiri | `>= 1.8, < 2`, installed automatically |
| rubyzip | `>= 1.3, < 4`, installed automatically |
| Rails | Not required |

## Install with Bundler

Add the gem to your Gemfile:

```ruby
gem "docxi", "~> 0.1"
```

Then install it:

```sh
bundle install
```

## Install without Bundler

```sh
gem install docxi
```

## Check the installation

```sh
ruby -e 'require "docxi"; puts Docxi::VERSION'
```

In a Bundler project, run it as `bundle exec ruby -e 'require "docxi"; puts Docxi::VERSION'`. It prints the installed version, for example `0.1.0`.

## Upgrading from 0.0.x

If your Gemfile pins docxi to 0.0.x, for example with `"~> 0.0.6"`, change the line to `gem "docxi", "~> 0.1"`. Then run `bundle update docxi`. No code changes are needed, and 0.1.0 generates the same documents as 0.0.6: the test suite compares the output against files generated by 0.0.6.

What changed under the hood:

- nokogiri and rubyzip can now be any version from the ranges above, so docxi installs next to current Rails versions.
- docxi no longer needs ActiveSupport to be loaded.
- Archives are written without Zip64 records.
- Images are loaded without `Kernel#open`, so URLs work on Ruby 3.
- `tab`, `frame` and header page numbers work.

Apps running a Ruby older than 2.5 keep getting 0.0.6, because 0.1.0 declares Ruby 2.5 as its minimum. The [Changelog](Changelog) lists every change.

## Platform notes

- nokogiri ships precompiled gems for common Linux, macOS and Windows platforms. Where none matches, it compiles from source and needs a C compiler. See the [nokogiri installation guide](https://nokogiri.org/tutorials/installing_nokogiri.html).
- CI runs on Ubuntu 24.04, and the tests have also been run on macOS. Windows isn't tested.

## If installation fails

Bundler conflicts on nokogiri or rubyzip almost always mean an old docxi 0.0.6 is being resolved. See [Troubleshooting](Troubleshooting#installation).
