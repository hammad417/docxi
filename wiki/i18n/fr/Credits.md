# Maintenance de docxi et crédits

Plusieurs personnes ont contribué à docxi depuis 2015. Cette page indique qui en assure la maintenance aujourd'hui, d'où vient le projet et qui y a contribué.

## <a id="maintainer"></a>Maintenance

La maintenance de docxi est assurée par [Hammad Maqbool](https://github.com/hammad417) chez [Phaedra Solutions](https://www.phaedrasolutions.com/). La gem sur RubyGems et le dépôt GitHub appartiennent au compte `hammad417`.

## <a id="history"></a>Historique

- **2015 :** Timur Gabdrakipov écrit [docxer](https://github.com/gtimti/docxer), une gem Ruby qui génère des fichiers `.docx`, publiée sous licence MIT.
- **2016 :** docxer est renommée docxi, adaptée et publiée en versions 0.0.1, 0.0.2 et 0.0.6. Le gemspec de ces versions indique le nom d'Irfan Babar dans le champ auteur.
- **2026 :** docxi 0.1.0 met la gem à jour pour les versions actuelles de Ruby, Rails et rubyzip sans modifier les documents qu'elle génère.

## <a id="contributors"></a>Contributions

L'historique git contient des commits de Hammad Maqbool. Il contient aussi des commits de 2016 dont le nom d'auteur a été enregistré sous la forme « = ». Le fichier LICENSE conserve la mention de copyright d'origine de Timur Gabdrakipov, comme l'exige la licence MIT.
