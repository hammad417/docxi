# docxi 维护者与致谢

自 2015 年以来，docxi 经过了多人的开发。本页记录了现在的维护者、项目的由来以及贡献者。

## <a id="maintainer"></a>维护者

docxi 由 [Phaedra Solutions](https://www.phaedrasolutions.com/) 的 [Hammad Maqbool](https://github.com/hammad417) 维护。RubyGems 上的 gem 和 GitHub 仓库都属于 `hammad417` 账号。

## <a id="history"></a>历史

- **2015 年**：Timur Gabdrakipov 编写了 [docxer](https://github.com/gtimti/docxer)，这是一个用于生成 `.docx` 文件的 Ruby gem，以 MIT 许可证发布。
- **2016 年**：docxer 更名为 docxi，经过改编后以 docxi 0.0.1、0.0.2 和 0.0.6 发布。这些版本的 gemspec 将 Irfan Babar 列为作者。
- **2026 年**：docxi 0.1.0 让该 gem 兼容当前的 Ruby、Rails 和 rubyzip，同时不改变它生成的文档。

## <a id="contributors"></a>贡献者

git 历史记录了 Hammad Maqbool 的提交，还记录了 2016 年的一些提交，其作者名被存储为“=”。LICENSE 文件按照 MIT 许可证的要求，保留了 Timur Gabdrakipov 的原始版权声明。

## <a id="about-phaedra-solutions"></a>关于 Phaedra Solutions

Phaedra Solutions 是一家 AI 优先的软件工程公司，自 2013 年起为企业构建定制软件。
