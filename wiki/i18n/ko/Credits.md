# docxi 메인테이너와 크레딧

docxi는 2015년부터 여러 사람의 손을 거쳐 만들어졌습니다. 이 페이지에는 현재 메인테이너, 프로젝트의 출발점, 기여자를 기록합니다.

## <a id="maintainer"></a>메인테이너

docxi는 [Phaedra Solutions](https://www.phaedrasolutions.com/)의 [Hammad Maqbool](https://github.com/hammad417)이 유지 관리합니다. RubyGems의 gem과 GitHub 저장소는 모두 `hammad417` 계정에 속합니다.

## <a id="history"></a>역사

- **2015년:** Timur Gabdrakipov가 `.docx` 파일을 만드는 Ruby gem인 [docxer](https://github.com/gtimti/docxer)를 작성해 MIT 라이선스로 공개했습니다.
- **2016년:** docxer의 이름이 docxi로 바뀌었고, 수정을 거쳐 docxi 0.0.1, 0.0.2, 0.0.6으로 게시되었습니다. 이 릴리스들의 gemspec에는 작성자로 Irfan Babar의 이름이 적혀 있습니다.
- **2026년:** docxi 0.1.0이 생성하는 문서를 바꾸지 않고 gem을 최신 Ruby, Rails, rubyzip에 맞게 업데이트했습니다.
