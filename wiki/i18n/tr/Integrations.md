# docxi'yi Rails, Rack ve arka plan işleriyle kullanma

docxi'nin eklentileri ve yerleşik entegrasyonları yoktur. Bir `StringIO` döndüren düz Ruby kodudur; bu yüzden bir dize gönderebildiğiniz veya saklayabildiğiniz her yerde çalışır. Bu sayfa, onu bağlamanın yaygın yollarını gösterir. Rails controller kalıbı README'de gösterilenle aynıdır ve test paketi Rails 5.2 ile 8.1 arası yüklüyken çalışır.

## <a id="rails-controller-send-the-file-to-the-browser"></a>Rails controller: dosyayı tarayıcıya gönderme

```ruby
class ReportsController < ApplicationController
  def show
    word = Docxi::Document.new
    word.document.p { |p| p.text "Report for #{Date.today}" }

    send_data word.render.string,
              filename: "report.docx",
              type: "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
  end
end
```

`send_data`, `Content-Disposition: attachment` başlığını ayarlar; böylece tarayıcı dosyayı indirir. Bundler kullanıldığında docxi, Gemfile üzerinden otomatik olarak yüklenir.

## <a id="rails-background-job-build-the-file-outside-the-request"></a>Rails arka plan işi: dosyayı isteğin dışında oluşturma

Büyük belgeleri veya yavaş sorgulardan oluşturulan belgeleri bir işte (job) oluşturmak daha iyidir:

```ruby
class MonthlyReportJob < ApplicationJob
  queue_as :default

  def perform(path)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Monthly report", bold: true, size: 16 }

    File.binwrite(path, word.render.string)
  end
end
```

İş, seçtiğiniz bir yola yazar. Dosyanın bundan sonra nereye gideceğine, örneğin bir depolama alanına veya e-postaya, uygulamanız karar verir.

## <a id="rack-and-other-frameworks"></a>Rack ve diğer çatılar

Herhangi bir Rack uygulaması baytları doğrudan döndürebilir:

```ruby
require "docxi"

class ReportApp
  def call(env)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Generated by a Rack app" }

    headers = {
      "content-type" => "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      "content-disposition" => 'attachment; filename="report.docx"'
    }
    [200, headers, [word.render.string]]
  end
end
```

Bunu `config.ru` içinde `run ReportApp.new` ile bağlayın. Aynı yaklaşım Sinatra, Hanami veya yanıt gövdesi olarak bir dize gönderebilen herhangi bir çatıda da çalışır.

## <a id="scripts-and-command-line-tools"></a>Betikler ve komut satırı araçları

docxi'nin sunucuya da ofis yazılımına da ihtiyacı yoktur; bu yüzden sıradan bir Ruby betiği yeterlidir:

```ruby
require "docxi"

word = Docxi::Document.new
word.document.p { |p| p.text "Nightly export" }
File.binwrite(ARGV.fetch(0, "export.docx"), word.render.string)
```
