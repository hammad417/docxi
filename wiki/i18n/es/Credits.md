# Mantenimiento y créditos de docxi

Varias personas han desarrollado docxi desde 2015. Esta página recoge quién lo mantiene ahora, de dónde viene y quién ha contribuido.

## <a id="maintainer"></a>Mantenimiento

docxi lo mantiene [Hammad Maqbool](https://github.com/hammad417) en [Phaedra Solutions](https://www.phaedrasolutions.com/). La gema en RubyGems y el repositorio de GitHub pertenecen a la cuenta `hammad417`.

## <a id="history"></a>Historia

- **2015:** Timur Gabdrakipov escribe [docxer](https://github.com/gtimti/docxer), una gema de Ruby para generar archivos `.docx`, publicada bajo la licencia MIT.
- **2016:** docxer pasa a llamarse docxi, se adapta y se publica como docxi 0.0.1, 0.0.2 y 0.0.6. El gemspec de esas versiones incluye a Irfan Babar en el campo de autoría.
- **2026:** docxi 0.1.0 pone la gema al día con las versiones actuales de Ruby, Rails y rubyzip sin cambiar los documentos que genera.

## <a id="contributors"></a>Contribuciones

El historial de git registra commits de Hammad Maqbool. También registra commits de 2016 cuyo nombre de autor se guardó como «=». El archivo LICENSE conserva el aviso de copyright original de Timur Gabdrakipov, como exige la licencia MIT.
