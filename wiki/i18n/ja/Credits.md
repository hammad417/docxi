# docxi のメンテナーとクレジット

docxi は 2015 年から複数の人によって作られてきました。このページでは、現在のメンテナー、プロジェクトの由来、コントリビューターを記録しています。

## <a id="maintainer"></a>メンテナー

docxi は [Phaedra Solutions](https://www.phaedrasolutions.com/) の [Hammad Maqbool](https://github.com/hammad417) がメンテナンスしています。RubyGems の gem と GitHub のリポジトリは、どちらも `hammad417` アカウントのものです。

## <a id="history"></a>歴史

- **2015 年**：Timur Gabdrakipov が、`.docx` ファイルを生成する Ruby の gem である [docxer](https://github.com/gtimti/docxer) を作成し、MIT ライセンスで公開しました。
- **2016 年**：docxer は docxi に名前を変え、手を加えたうえで docxi 0.0.1、0.0.2、0.0.6 として公開されました。これらのリリースの gemspec には、作成者として Irfan Babar の名前が記載されています。
- **2026 年**：docxi 0.1.0 で、生成するドキュメントを変えずに、gem を現行の Ruby、Rails、rubyzip に対応させました。

## <a id="contributors"></a>コントリビューター

git の履歴には Hammad Maqbool のコミットが記録されています。また、作成者名が「=」として保存された 2016 年のコミットも記録されています。LICENSE ファイルには、MIT ライセンスの定めに従って、Timur Gabdrakipov による元の著作権表示が残されています。

## <a id="about-phaedra-solutions"></a>Phaedra Solutions について

Phaedra Solutions は、AI ファーストのソフトウェアエンジニアリング企業で、2013 年から企業向けにカスタムソフトウェアを開発しています。
