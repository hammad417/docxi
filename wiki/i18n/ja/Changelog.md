## <a id="011"></a>0.1.1

コードの変更はなく、生成されるドキュメントは 0.1.0 と同じです。

- gem の概要と説明で docxi が何をするのかを説明するようにしました。以前はテンプレート生成ツールと説明していました。
- RubyGems から gem のドキュメントとしてこの Wiki にリンクしています。

## <a id="010"></a>0.1.0

**互換性**

- Ruby 2.5 以降が必要です。それより古い Ruby のアプリケーションは 0.0.6 のままになります。
- Rails の有無にかかわらず動作し、Rails 5.2 から 8.1 と組み合わせてテストしています。
- nokogiri の要件を `>= 1.6.3, < 1.7` から `>= 1.8, < 2` に変更しました。以前の範囲は Rails 6.0 以降のすべてのバージョンと競合していました。
- rubyzip の要件を `~> 0.9.9` から `>= 1.3, < 4` に変更しました。
- ActiveSupport の `blank?` と `present?` を呼ばなくなりました。これらは Rails が読み込んでいるときにしか動きませんでした。

**修正**

- rubyzip 3 で書き出したドキュメントに Zip64 レコードが含まれなくなりました。Google Docs や古いバージョンの LibreOffice はこのレコードを受け付けません。
- 画像の URL を渡した `add_media` が Ruby 3 で再び動くようになりました。
- `add_media` は `|` で始まる文字列をシェルコマンドとして実行しなくなりました。
- `tab` と `frame` が `NameError` を発生させなくなりました。
- `document.frame("text")` は、そのテキストを含むテキストボックスを作成します。
- ヘッダー内の `page_numbers` が `NameError` を発生させなくなりました。

**gem**

- メンテナー、ホームページ、変更履歴へのリンクを更新しました。
- リリースには MFA が必要です。
