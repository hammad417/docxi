# Memakai docxi dengan Rails, Rack, dan job latar belakang

docxi tidak punya plugin dan tidak punya integrasi bawaan. docxi adalah Ruby biasa yang mengembalikan `StringIO`, sehingga bisa dipakai di mana pun Anda dapat mengirim atau menyimpan string. Halaman ini menunjukkan cara-cara umum untuk menghubungkannya. Pola controller Rails di sini sama dengan yang ada di README, dan rangkaian pengujiannya dijalankan dengan Rails 5.2 sampai 8.1 dalam keadaan termuat.

## <a id="rails-controller-send-the-file-to-the-browser"></a>Controller Rails: mengirim file ke browser

```ruby
class ReportsController < ApplicationController
  def show
    word = Docxi::Document.new
    word.document.p { |p| p.text "Report for #{Date.today}" }

    send_data word.render.string,
              filename: "report.docx",
              type: "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
  end
end
```

`send_data` mengatur `Content-Disposition: attachment`, sehingga browser mengunduh file tersebut. Dengan Bundler, docxi dimuat otomatis dari Gemfile.

## <a id="rails-background-job-build-the-file-outside-the-request"></a>Job latar belakang Rails: membuat file di luar permintaan

Dokumen besar, atau dokumen yang dibangun dari kueri yang lambat, lebih baik dibuat di sebuah job:

```ruby
class MonthlyReportJob < ApplicationJob
  queue_as :default

  def perform(path)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Monthly report", bold: true, size: 16 }

    File.binwrite(path, word.render.string)
  end
end
```

Job tersebut menulis ke path yang Anda pilih. Ke mana file itu pergi selanjutnya, misalnya ke penyimpanan atau email, diatur oleh aplikasi Anda.

## <a id="rack-and-other-frameworks"></a>Rack dan framework lain

Aplikasi Rack apa pun bisa langsung mengembalikan byte-nya:

```ruby
require "docxi"

class ReportApp
  def call(env)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Generated by a Rack app" }

    headers = {
      "content-type" => "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      "content-disposition" => 'attachment; filename="report.docx"'
    }
    [200, headers, [word.render.string]]
  end
end
```

Pasang dengan `run ReportApp.new` di `config.ru`. Pendekatan yang sama berlaku untuk Sinatra, Hanami, atau framework apa pun yang bisa mengirim string sebagai badan respons.

## <a id="scripts-and-command-line-tools"></a>Skrip dan alat baris perintah

docxi tidak memerlukan server maupun perangkat lunak perkantoran, jadi skrip Ruby biasa sudah cukup:

```ruby
require "docxi"

word = Docxi::Document.new
word.document.p { |p| p.text "Nightly export" }
File.binwrite(ARGV.fetch(0, "export.docx"), word.render.string)
```
