# Pengelola dan kredit docxi

Sejak 2015, docxi sudah dikerjakan oleh beberapa orang. Halaman ini mencatat siapa yang mengelolanya sekarang, dari mana asalnya, dan siapa saja yang berkontribusi.

## <a id="maintainer"></a>Pengelola

docxi dikelola oleh [Hammad Maqbool](https://github.com/hammad417) di [Phaedra Solutions](https://www.phaedrasolutions.com/). Gem di RubyGems dan repositori GitHub-nya milik akun `hammad417`.

## <a id="history"></a>Riwayat

- **2015:** Timur Gabdrakipov menulis [docxer](https://github.com/gtimti/docxer), gem Ruby untuk membuat file `.docx`, yang dirilis di bawah lisensi MIT.
- **2016:** docxer berganti nama menjadi docxi, disesuaikan, lalu diterbitkan sebagai docxi 0.0.1, 0.0.2, dan 0.0.6. Gemspec rilis-rilis tersebut mencantumkan Irfan Babar sebagai penulis.
- **2026:** docxi 0.1.0 memperbarui gem ini agar sesuai dengan Ruby, Rails, dan rubyzip terkini tanpa mengubah dokumen yang dihasilkannya.

## <a id="contributors"></a>Kontributor

Riwayat git mencatat commit dari Hammad Maqbool. Riwayat itu juga mencatat commit dari 2016 yang nama penulisnya tersimpan sebagai "=". File LICENSE mempertahankan pemberitahuan hak cipta asli milik Timur Gabdrakipov, sebagaimana diwajibkan oleh lisensi MIT.

Phaedra Solutions adalah perusahaan rekayasa perangkat lunak yang mengutamakan AI dan telah membangun perangkat lunak khusus untuk berbagai bisnis sejak 2013.
