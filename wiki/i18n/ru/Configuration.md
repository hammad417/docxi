# Настройка docxi: поля страницы, параметры страницы и единицы измерения

У docxi нет файла конфигурации, переменных окружения и глобальных настроек. Всё задаётся для каждого документа или элемента отдельно. На этой странице описаны настройки уровня документа и единицы, в которых указываются параметры. Параметры отдельных элементов перечислены в разделе [Возможности](Features).

## <a id="page-margins"></a>Поля страницы

Поля передаются при создании документа:

```ruby
require "docxi"

# Все значения указаны в двадцатых долях пункта (1440 = 1 дюйм).
word = Docxi::Document.new(top: 1440, right: 1080, bottom: 1440, left: 1080, header: 720, footer: 720)
word.document.p { |p| p.text "One-inch top and bottom margins" }

File.binwrite("margins.docx", word.render.string)
```

| Параметр | По умолчанию | Значение |
|---|---|---|
| `top` | `720` (0,5 дюйма) | Верхнее поле |
| `right` | `1440` (1 дюйм) | Правое поле |
| `bottom` | `720` (0,5 дюйма) | Нижнее поле |
| `left` | `1440` (1 дюйм) | Левое поле |
| `header` | `190` | Расстояние от верхнего края страницы до верхнего колонтитула |
| `footer` | `200` | Расстояние от нижнего края страницы до нижнего колонтитула |

Переданный хеш заменяет значения по умолчанию целиком, поэтому задавайте `top`, `right`, `bottom` и `left` вместе. Любое из этих четырёх значений, которое вы пропустите, записывается пустым. Для `header` и `footer` при отсутствии или пустом значении используются 190 и 200.

## <a id="page-size-and-orientation"></a>Размер и ориентация страницы

Страницы имеют формат US Letter в книжной ориентации: 12240 × 15840 двадцатых долей пункта, то есть 8,5 × 11 дюймов. В 0.1.0 размер и ориентацию изменить нельзя.

## <a id="first-page"></a>Первая страница

docxi всегда включает в Word параметр «Особый колонтитул для первой страницы». Колонтитулы, добавленные через `add_header` и `add_footer`, используются начиная со страницы 2. Для страницы 1 используются `add_first_header` и `add_first_footer`, поэтому задайте и их, если первой странице нужен колонтитул. См. [Возможности](Features#headers-and-footers).

## <a id="what-every-document-contains"></a>Что содержит каждый документ

- Шрифт по умолчанию — Arial 12 pt.
- Определённые стили: `Normal`, `DefaultParagraphFont`, `TableNormal`, `TableCustom` и `NoList`.
- Элементы маркированного списка (`ul: true`) используют тире в качестве маркера.
- Свойства документа указывают «Docxi Ruby Gem» как название приложения и хранят время, когда документ был сформирован.

## <a id="units"></a>Единицы измерения

| Параметр | Единица |
|---|---|
| `size:` текста | Пункты (docxi удваивает значение, переводя его в половины пункта, как в Word) |
| Поля, `left:` и `right:` абзаца, `iwidth:` таблицы, `height:` строки | Двадцатые доли пункта (1440 на дюйм) |
| Толщина `borders:` ячейки | Восьмые доли пункта |
| `columns_width:` и `width:` ячейки | Умножаются на 14.92 для перевода в двадцатые доли пункта, что близко к пикселям при 96 dpi |
| `style:` встроенного изображения | Длины CSS, например `"120pt"` |
| `pH:` и `pV:` позиционированного изображения | EMU (914400 на дюйм) |
| Цвета текста и заливки | Шестнадцатеричное значение без `#`, например `"8B0000"` |
| `fill_color:` изображения | Цвет VML с `#`, например `"#00FF00"` |
