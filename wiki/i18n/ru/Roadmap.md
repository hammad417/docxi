# Планы развития docxi и известные проблемы

У docxi нет графика выпусков и утверждённого плана развития. Единственная записанная запланированная работа — исправление перечисленных ниже известных проблем. Оно планируется в 0.2.0, без конкретной даты. В 0.1.0 эти исправления не вошли, потому что они меняют документы, которые нынешние пользователи уже создают.

## <a id="known-issues-planned-for-020"></a>Известные проблемы, запланированные на 0.2.0

| Проблема | Обходной путь в 0.1.0 |
|---|---|
| Позиционированные изображения, изображения в колонтитулах и в ячейках таблиц вычисляют размер по обоим измерениям как `width * height * 14.92` EMU | Используйте встроенные изображения с размером, заданным через `style:`, или см. [Рекомендации](Best-Practices#images) |
| `borders:` на уровне таблицы применяются к каждой ячейке, а не к внешнему контуру таблицы | Чтобы получить только контур, задавайте `borders:` для внешних сторон крайних ячеек |
| В коде поля номера страницы не хватает обратной косой черты в `\* MERGEFORMAT` | Нет |
| Перед номерами страниц в ячейках таблиц выводится «GlobalOptions» | Размещайте номера страниц в колонтитулах |
| Изображения всегда сохраняются как части PNG, а `[Content_Types].xml` объявляет только первые два верхних и два нижних колонтитула | Используйте изображения PNG и не более двух верхних и двух нижних колонтитулов |
| Если передать только часть полей, остальные записываются пустыми | Передавайте `top`, `right`, `bottom` и `left` вместе |
| `docProps/core.xml` записывает местное время с отметкой UTC и никогда не записывает автора | Нет |
| `Docxi.test` вызывает `NoMethodError` | Не вызывайте его. Это вспомогательный метод, оставшийся от старых версий |
| `document.br` и `document.tab` без `page: true` создают недопустимый XML | Используйте `p.br` и `p.tab` внутри абзаца |

## <a id="not-planned"></a>Не запланировано

Этих пунктов нет в списке выше, и по ним ничего не решено:

- редактирование существующих документов или заполнение шаблонов
- нумерованные списки, стили заголовков или автоматическое оглавление
- другие размеры страниц или альбомная ориентация
