# Сопровождение docxi и благодарности

С 2015 года над docxi работали несколько человек. На этой странице записано, кто сопровождает проект сейчас, откуда он взялся и кто в него внёс вклад.

## <a id="maintainer"></a>Сопровождение

Сопровождением docxi занимается [Hammad Maqbool](https://github.com/hammad417) в [Phaedra Solutions](https://www.phaedrasolutions.com/). Гем на RubyGems и репозиторий на GitHub принадлежат аккаунту `hammad417`.

## <a id="history"></a>История

- **2015:** Timur Gabdrakipov пишет [docxer](https://github.com/gtimti/docxer) — Ruby-гем для создания файлов `.docx`, выпущенный под лицензией MIT.
- **2016:** docxer переименовывают в docxi, дорабатывают и публикуют как docxi 0.0.1, 0.0.2 и 0.0.6. В поле автора в gemspec этих версий указано имя Irfan Babar.
- **2026:** docxi 0.1.0 обновляет гем для актуальных Ruby, Rails и rubyzip, не меняя создаваемые им документы.

## <a id="contributors"></a>Участники
