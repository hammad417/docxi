# docxi с Rails, Rack и фоновыми задачами

У docxi нет плагинов и встроенных интеграций. Это обычный Ruby, который возвращает `StringIO`, поэтому он работает везде, где можно отправить или сохранить строку. На этой странице показаны обычные способы подключения. Вариант с контроллером Rails совпадает с примером из README, а набор тестов запускается с загруженными Rails от 5.2 до 8.1.

## <a id="rails-controller-send-the-file-to-the-browser"></a>Контроллер Rails: отправка файла в браузер

```ruby
class ReportsController < ApplicationController
  def show
    word = Docxi::Document.new
    word.document.p { |p| p.text "Report for #{Date.today}" }

    send_data word.render.string,
              filename: "report.docx",
              type: "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
  end
end
```

`send_data` устанавливает `Content-Disposition: attachment`, поэтому браузер скачивает файл. С Bundler docxi загружается из Gemfile автоматически.

## <a id="rails-background-job-build-the-file-outside-the-request"></a>Фоновая задача Rails: формирование файла вне запроса

Большие документы или документы, которые строятся по медленным запросам, лучше формировать в задаче:

```ruby
class MonthlyReportJob < ApplicationJob
  queue_as :default

  def perform(path)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Monthly report", bold: true, size: 16 }

    File.binwrite(path, word.render.string)
  end
end
```

Задача записывает файл по выбранному вами пути. Куда файл отправится дальше, например в хранилище или в письмо, решает ваше приложение.

## <a id="rack-and-other-frameworks"></a>Rack и другие фреймворки

Любое приложение Rack может вернуть байты напрямую:

```ruby
require "docxi"

class ReportApp
  def call(env)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Generated by a Rack app" }

    headers = {
      "content-type" => "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      "content-disposition" => 'attachment; filename="report.docx"'
    }
    [200, headers, [word.render.string]]
  end
end
```

Подключите его через `run ReportApp.new` в `config.ru`. Тот же подход работает с Sinatra, Hanami и любым фреймворком, который умеет отдавать строку как тело ответа.

## <a id="scripts-and-command-line-tools"></a>Скрипты и утилиты командной строки

docxi не нужны ни сервер, ни офисные программы, поэтому достаточно обычного скрипта на Ruby:

```ruby
require "docxi"

word = Docxi::Document.new
word.document.p { |p| p.text "Nightly export" }
File.binwrite(ARGV.fetch(0, "export.docx"), word.render.string)
```
