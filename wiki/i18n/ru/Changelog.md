# Журнал изменений и история версий docxi

На этой странице кратко описана каждая версия. Полные заметки находятся в файле [`CHANGELOG.md`](https://github.com/hammad417/docxi/blob/master/CHANGELOG.md) в репозитории, и при расхождениях верен именно он.

## <a id="releases"></a>Версии

| Версия | Дата | Примечания |
|---|---|---|
| 0.1.1 | 2026-10-29 | Более точные краткое описание и описание гема, ссылка на документацию. Код не менялся |
| 0.1.0 | 2026-10-28 | Работает с актуальными Ruby, Rails и rubyzip. Создаёт те же документы, что и 0.0.6 |
| 0.1.0.rc1 | 2026-10-28 | Предварительная версия 0.1.0 |
| 0.0.6 | 2016-10-18 | Последняя версия перед обновлением до 0.1.0 |
| 0.0.2 | 2016-10-14 | Заметки к выпуску не сохранились |
| 0.0.1 | 2016-10-14 | Первая версия. Заметки к выпуску не сохранились |

Версии с 0.0.3 по 0.0.5 никогда не публиковались в RubyGems.

## <a id="011"></a>0.1.1

Код не менялся, создаваемые документы такие же, как в 0.1.0.

- Краткое описание и описание гема теперь говорят, что делает docxi. Раньше его называли генератором шаблонов.
- RubyGems ссылается на эту вики как на документацию гема.

## <a id="010"></a>0.1.0

**Совместимость**

- Требуется Ruby 2.5 или новее. Приложения на более старых версиях Ruby остаются на 0.0.6.
- Работает с Rails и без него, проверяется вместе с Rails от 5.2 до 8.1.
- nokogiri `>= 1.8, < 2` вместо `>= 1.6.3, < 1.7`, что конфликтовало со всеми версиями Rails начиная с 6.0.
- rubyzip `>= 1.3, < 4` вместо `~> 0.9.9`.
- Больше не вызывает `blank?` и `present?` из ActiveSupport, которые работали, только если их загрузил Rails.

**Исправления**

- Документы, записанные с rubyzip 3, больше не содержат записей Zip64, которые отклоняют Google Docs и старые версии LibreOffice.
- `add_media` с URL изображения снова работает в Ruby 3.
- `add_media` больше не выполняет строку, начинающуюся с `|`, как команду оболочки.
- `tab` и `frame` больше не вызывают `NameError`.
- `document.frame("text")` создаёт надпись с этим текстом.
- `page_numbers` в верхнем колонтитуле больше не вызывает `NameError`.

**Гем**

- Смена сопровождения, новые ссылки на домашнюю страницу и журнал изменений.
- Для публикации версий требуется MFA.
