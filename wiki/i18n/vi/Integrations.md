# Dùng docxi với Rails, Rack và tác vụ nền

docxi không có plugin và không có tích hợp dựng sẵn. Đây là mã Ruby thuần trả về một `StringIO`, nên hoạt động ở bất cứ đâu bạn có thể gửi hoặc lưu một chuỗi. Trang này trình bày những cách kết nối thường dùng. Mẫu controller của Rails là mẫu được nêu trong README, và bộ kiểm thử chạy với Rails từ 5.2 đến 8.1 được nạp.

## <a id="rails-controller-send-the-file-to-the-browser"></a>Controller của Rails: gửi tệp tới trình duyệt

```ruby
class ReportsController < ApplicationController
  def show
    word = Docxi::Document.new
    word.document.p { |p| p.text "Report for #{Date.today}" }

    send_data word.render.string,
              filename: "report.docx",
              type: "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
  end
end
```

`send_data` đặt `Content-Disposition: attachment`, nên trình duyệt sẽ tải tệp xuống. Khi dùng Bundler, docxi được nạp tự động từ Gemfile.

## <a id="rails-background-job-build-the-file-outside-the-request"></a>Tác vụ nền của Rails: tạo tệp bên ngoài yêu cầu

Tài liệu lớn, hoặc tài liệu được dựng từ các truy vấn chậm, nên được tạo trong một tác vụ (job):

```ruby
class MonthlyReportJob < ApplicationJob
  queue_as :default

  def perform(path)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Monthly report", bold: true, size: 16 }

    File.binwrite(path, word.render.string)
  end
end
```

Tác vụ ghi tệp vào đường dẫn bạn chọn. Tệp được chuyển đi đâu tiếp theo, chẳng hạn vào kho lưu trữ hay gửi qua email, là do ứng dụng của bạn quyết định.

## <a id="rack-and-other-frameworks"></a>Rack và các framework khác

Bất kỳ ứng dụng Rack nào cũng có thể trả về các byte trực tiếp:

```ruby
require "docxi"

class ReportApp
  def call(env)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Generated by a Rack app" }

    headers = {
      "content-type" => "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      "content-disposition" => 'attachment; filename="report.docx"'
    }
    [200, headers, [word.render.string]]
  end
end
```

Gắn ứng dụng bằng `run ReportApp.new` trong `config.ru`. Cách làm tương tự áp dụng được cho Sinatra, Hanami hoặc bất kỳ framework nào có thể gửi một chuỗi làm phần thân phản hồi.

## <a id="scripts-and-command-line-tools"></a>Script và công cụ dòng lệnh

docxi không cần máy chủ cũng không cần phần mềm văn phòng, nên một script Ruby thông thường là đủ:

```ruby
require "docxi"

word = Docxi::Document.new
word.document.p { |p| p.text "Nightly export" }
File.binwrite(ARGV.fetch(0, "export.docx"), word.render.string)
```
