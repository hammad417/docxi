# خارطة طريق docxi والمشكلات المعروفة

ليس لمكتبة docxi جدول إصدارات ولا خارطة طريق ملتزم بها. العمل المخطط الوحيد المسجّل هو إصلاح المشكلات المعروفة أدناه، وهو مخطط له في الإصدار 0.2.0 دون موعد محدد. أُبقيت هذه الإصلاحات خارج الإصدار 0.1.0 لأنها تغيّر المستندات التي يولّدها المستخدمون الحاليون بالفعل.

## <a id="known-issues-planned-for-020"></a>المشكلات المعروفة المخطط إصلاحها في الإصدار 0.2.0

| المشكلة | الحل البديل في الإصدار 0.1.0 |
|---|---|
| تحسب الصور المحددة الموضع وصور رؤوس الصفحات وصور خلايا الجداول حجمها على أنه <span dir="ltr">`width * height * 14.92`</span> EMU في البعدين كليهما | استخدم صورًا مضمّنة يُضبط حجمها عبر <span dir="ltr">`style:`</span>، أو راجع [أفضل الممارسات](Best-Practices#images) |
| يُطبَّق الخيار <span dir="ltr">`borders:`</span> على مستوى الجدول على كل خلية بدلًا من الحواف الخارجية للجدول | للحصول على الإطار الخارجي فقط، اضبط <span dir="ltr">`borders:`</span> على الجوانب الخارجية للخلايا الواقعة على أطراف الجدول |
| يُكتب رمز حقل رقم الصفحة دون الشرطة المائلة العكسية في <span dir="ltr">`\* MERGEFORMAT`</span> | لا يوجد |
| تسبق أرقامَ الصفحات في خلايا الجداول عبارةُ «GlobalOptions» | ضع أرقام الصفحات في رأس الصفحة أو تذييلها |
| تُخزَّن الصور دائمًا كأجزاء PNG، ولا يصرّح <span dir="ltr">`[Content_Types].xml`</span> إلا بأول رأسين وأول تذييلين | استخدم صور PNG، وبحد أقصى رأسين وتذييلين |
| تمرير بعض الهوامش فقط يكتب البقية فارغة | مرّر <span dir="ltr">`top`</span> و<span dir="ltr">`right`</span> و<span dir="ltr">`bottom`</span> و<span dir="ltr">`left`</span> معًا |
| يسجّل <span dir="ltr">`docProps/core.xml`</span> التوقيت المحلي بعلامة UTC ولا يكتب المؤلف أبدًا | لا يوجد |
| استدعاء <span dir="ltr">`Docxi.test`</span> يطلق <span dir="ltr">`NoMethodError`</span> | لا تستدعِها، فهي دالة مساعدة متبقية |
| تنتج <span dir="ltr">`document.br`</span> و<span dir="ltr">`document.tab`</span> دون <span dir="ltr">`page: true`</span> ملف XML غير صالح | استخدم <span dir="ltr">`p.br`</span> و<span dir="ltr">`p.tab`</span> داخل فقرة |

## <a id="not-planned"></a>غير مخطط له

هذه البنود ليست في القائمة أعلاه، ولم يُتخذ أي قرار بشأنها:

- تعديل المستندات الموجودة أو ملء القوالب
- القوائم المرقمة أو أنماط العناوين أو جدول المحتويات التلقائي
- مقاسات صفحات أخرى أو صفحات أفقية
