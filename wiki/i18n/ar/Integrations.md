# استخدام docxi مع Rails وRack والمهام في الخلفية

ليس لمكتبة docxi إضافات ولا تكاملات مدمجة. إنها شيفرة Ruby عادية تعيد كائن <span dir="ltr">`StringIO`</span>، لذا تعمل في أي مكان يمكنك فيه إرسال سلسلة نصية أو تخزينها. تعرض هذه الصفحة الطرق المعتادة لربطها. نمط وحدة التحكم في Rails هو النمط الذي يعرضه ملف README، وتعمل مجموعة الاختبارات مع تحميل Rails من 5.2 إلى 8.1.

## <a id="rails-controller-send-the-file-to-the-browser"></a>وحدة تحكم في Rails: إرسال الملف إلى المتصفح

```ruby
class ReportsController < ApplicationController
  def show
    word = Docxi::Document.new
    word.document.p { |p| p.text "Report for #{Date.today}" }

    send_data word.render.string,
              filename: "report.docx",
              type: "application/vnd.openxmlformats-officedocument.wordprocessingml.document"
  end
end
```

تضبط <span dir="ltr">`send_data`</span> الترويسة <span dir="ltr">`Content-Disposition: attachment`</span>، فيُنزّل المتصفح الملف. ومع Bundler تُحمَّل docxi تلقائيًا من ملف Gemfile.

## <a id="rails-background-job-build-the-file-outside-the-request"></a>مهمة في الخلفية في Rails: بناء الملف خارج الطلب

من الأفضل إنشاء المستندات الكبيرة، أو المستندات المبنية من استعلامات بطيئة، في مهمة في الخلفية:

```ruby
class MonthlyReportJob < ApplicationJob
  queue_as :default

  def perform(path)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Monthly report", bold: true, size: 16 }

    File.binwrite(path, word.render.string)
  end
end
```

تكتب المهمة إلى مسار تختاره. أما وجهة الملف بعد ذلك، كالتخزين أو البريد الإلكتروني، فتعود إلى تطبيقك.

## <a id="rack-and-other-frameworks"></a>إطار Rack وأطر العمل الأخرى

يمكن لأي تطبيق Rack أن يعيد البايتات مباشرة:

```ruby
require "docxi"

class ReportApp
  def call(env)
    word = Docxi::Document.new
    word.document.p { |p| p.text "Generated by a Rack app" }

    headers = {
      "content-type" => "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      "content-disposition" => 'attachment; filename="report.docx"'
    }
    [200, headers, [word.render.string]]
  end
end
```

شغّله باستخدام <span dir="ltr">`run ReportApp.new`</span> في <span dir="ltr">`config.ru`</span>. ويصلح الأسلوب نفسه مع Sinatra وHanami وأي إطار عمل يمكنه إرسال سلسلة نصية كمتن للاستجابة.

## <a id="scripts-and-command-line-tools"></a>السكربتات وأدوات سطر الأوامر

لا تحتاج docxi إلى خادم ولا إلى برامج مكتبية، لذا يكفي سكربت Ruby عادي:

```ruby
require "docxi"

word = Docxi::Document.new
word.document.p { |p| p.text "Nightly export" }
File.binwrite(ARGV.fetch(0, "export.docx"), word.render.string)
```
