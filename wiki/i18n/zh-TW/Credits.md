# docxi 維護者與致謝

自 2015 年以來，docxi 經過多人的開發。本頁記錄了目前的維護者、專案的由來以及貢獻者。

## <a id="maintainer"></a>維護者

docxi 由 [Phaedra Solutions](https://www.phaedrasolutions.com/) 的 [Hammad Maqbool](https://github.com/hammad417) 維護。RubyGems 上的 gem 和 GitHub 儲存庫都屬於 `hammad417` 帳號。

## <a id="history"></a>歷史

- **2015 年**：Timur Gabdrakipov 撰寫了 [docxer](https://github.com/gtimti/docxer)，這是一個用來產生 `.docx` 檔案的 Ruby gem，以 MIT 授權條款發布。
- **2016 年**：docxer 更名為 docxi，經過改寫後以 docxi 0.0.1、0.0.2 和 0.0.6 發布。這些版本的 gemspec 將 Irfan Babar 列為作者。
- **2026 年**：docxi 0.1.0 讓這個 gem 相容於目前的 Ruby、Rails 和 rubyzip，同時不改變它產生的文件。

## <a id="contributors"></a>貢獻者

git 歷史記錄了 Hammad Maqbool 的提交，也記錄了 2016 年的一些提交，其作者名稱被儲存為「=」。LICENSE 檔案依照 MIT 授權條款的要求，保留了 Timur Gabdrakipov 的原始著作權聲明。
