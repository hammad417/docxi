# Manutenção e créditos do docxi

Várias pessoas contribuíram com o docxi desde 2015. Esta página registra quem cuida da manutenção hoje, de onde o projeto veio e quem contribuiu.

## <a id="maintainer"></a>Manutenção

A manutenção do docxi é feita por [Hammad Maqbool](https://github.com/hammad417), na [Phaedra Solutions](https://www.phaedrasolutions.com/). A gem no RubyGems e o repositório no GitHub pertencem à conta `hammad417`.

## <a id="history"></a>Histórico

- **2015:** Timur Gabdrakipov escreve o [docxer](https://github.com/gtimti/docxer), uma gem Ruby para gerar arquivos `.docx`, lançada sob a licença MIT.
- **2016:** o docxer é renomeado para docxi, adaptado e publicado como docxi 0.0.1, 0.0.2 e 0.0.6. O gemspec dessas versões traz o nome de Irfan Babar no campo de autoria.
- **2026:** o docxi 0.1.0 atualiza a gem para as versões atuais do Ruby, do Rails e do rubyzip sem mudar os documentos que ela gera.

## <a id="contributors"></a>Contribuições

O histórico do git registra commits de Hammad Maqbool. Também registra commits de 2016 cujo nome de autor foi gravado como "=". O arquivo LICENSE mantém o aviso de copyright original de Timur Gabdrakipov, como a licença MIT exige.
